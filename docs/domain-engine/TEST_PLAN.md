# 验收与测试计划

所有云端测试使用版本化合成文件、Mock LLM、确定性 embedding 与独立数据库；禁止真实专有论文和模型密钥。通过调用参数与返回 fixture 验证契约，比对记录、引用与事件而非比较生成文案。单元测试覆盖解析、Schema 编译、JSON Path 子集、引用解析、定位、数值及单位、所有权、状态机。集成使用 PostgreSQL + Redis，模拟仅启动进程的测试不能证明数据一致性。

| 场景 | 合成输入及验收结果 |
| --- | --- |
| 化妆品 | 一份带 A/B 配方、对照、关键材料、背景组分、测量条件和单元格定位的合成报告。Flow 1 fixture 保持 18 根字段，Flow 2 23 根字段，核实方法/配方/发现的局部 ID、三类性质中重名 ID 和表格证据。对缺失条件或冲突配方关系生成 review。派生引用回到原表，且 AI 推断从展示可识别 |
| 汽车 | 合成台架报告含 `vehicle_platforms`、`test_conditions`、`measurements`、`failures`，Flow 2 用独立的 `normalized_components`、`failure_modes` 和链接。复用同一个二进制、流水线、DB 与 Vue，按试验温度和失效类别过滤、分组计数、查证据。原料/配方字段不存在仍然可用，字段只由映射决定 |
| 契约负例 | duplicate key、类型错、非法 null、无效路径、未声明键、局部 ID 重复及不存在、截断、假原文验证、空结果差异。验证错误可解释且不激活。Mock 断言 Flow 2 请求包含完整有效 Flow 1 JSON，原文哨兵只出现在 Flow 1 或可选 Evidence Audit |
| 注入与隔离 | 文档含“忽略提示”与外部请求文本，Mock 捕获关闭工具，导入拒绝远程引用及 ZIP 路径越界。跨租户按猜测 ID、反查证据、统计、导出、索引、Agent 及缓存均不可访问；撤权和删除后旧 URL/结果不可访问 |
| 容错 | 阶段发布前杀进程、模型成功但响应超时、相同工作重复投递、重启导致租约过期、429、取消和源替换并发、Redis 丢消息、索引失败。确认只推进一次有效 generation，保留失败 attempt 并继续原生索引。成功后继阶段无需重复调用 |
| 版本与生命周期 | 发布时正在运行的作业继续用旧配置；重跑可按失效规则复用；映射变更不调用模型；旧 generation 保留且无法越权查询；导出/恢复后原件和证据哈希相符，索引可重建 |
| 原生回归 | 无 profile、不同角色、普通知识/FAQ/Wiki、上传/下载、重解析、索引检索及问答继续走既有逻辑。验证 Redis/SQLite Lite 进程内执行模式在领域关闭时一致 |
| 吞吐 | 并行批上传，模拟慢模型及取消，测原生解析/检索延时、队列等待、内存、重试率和 token 费用，报告基线、并发配置及差异 |

本地验收检查 ARM64 具体镜像与解析引擎、MiniMax 区域/账户/模型额度、普通及结构化输出、Usage、真实文献定位和保密约束。Phase 1 无新业务实现，以上为实施门，不将 Mock 的科学结果当作真实质量评估。
